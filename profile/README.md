# Alex's Piano Service

**Piano service, web development, and software tools for Yamaha Disklavier and legacy music technology workflows.**

Alex's Piano Service LLC is a piano service company based in Maine, specializing in acoustic piano service, digital piano repair, Yamaha Disklavier systems, MIDI workflows, floppy disk preservation, and practical tools for older player-piano systems.

This GitHub organization hosts software projects related to:

- Yamaha Disklavier file preparation
- MIDI and E-SEQ conversion
- PIANODIR.FIL generation and repair
- Yamaha PianoSoft floppy disk reading
- Nalbantov, Gotek, HFE, IMG, and Greaseweazle workflows
- WordPress tools used on [alexanderpeppe.com](https://www.alexanderpeppe.com/)
- Web-based utilities for musicians, technicians, and player-piano owners

## Main Projects

### APS MIDI Prep Tool

APS MIDI Prep Tool is a desktop utility for Windows and Linux that helps prepare Yamaha Disklavier and player-piano files. It can read Yamaha floppy disks, convert between MIDI and Yamaha E-SEQ, edit displayed song titles, shorten filenames for older systems, convert MIDI Type 1 files to Type 0, and work with floppy image workflows.

It is designed to replace a collection of older, fragile, and confusing utilities with a single modern tool built around real service workflows.

Typical uses include:

- Backing up Yamaha PianoSoft floppy disks
- Recovering readable files from aging disks
- Converting E-SEQ files to standard MIDI
- Preparing MIDI files for older Disklaviers
- Creating or refreshing PIANODIR.FIL
- Editing song titles shown on Disklavier and player-piano displays
- Preparing files for Nalbantov and Gotek floppy emulators

### Floppy Image Conversion Tools

These projects support online and server-side floppy image workflows, including conversion between legacy disk image formats and more accessible archive formats. Some tools are designed for integration with WordPress pages on alexanderpeppe.com.

## Development Goals

The goal of these projects is to make difficult legacy music-technology workflows safer, clearer, and more accessible.

Older Disklavier and player-piano systems often depend on older formats and Yamaha-specific file structures. These details are easy to get wrong, and mistakes can make disks or files appear unreadable.

These tools are built to reduce that friction.
